DARE automação

Guia de uso passo a passo, para quem não é da área de informática

Para que serve este programa? Ele faz sozinho um trabalho que você faria com muitos cliques: (1) preenche o DARE no site da Sefin, (2) salva o PDF do DARE no computador e (3) anexa esse PDF no processo certo do SEI. Você só informa os dados (digitando ou usando uma planilha) e acompanha.
Calma, é mais simples do que parece Você não precisa entender de computador. Basta seguir os passos na ordem. O programa vai fazendo perguntas e, em quase todas, é só digitar a resposta e apertar a tecla Enter. Se errar, quase tudo pode ser corrigido antes de começar.

1. Antes de começar

Para usar o programa você precisa de:

  • Um computador com Windows.
  • O navegador Google Chrome instalado.
  • Internet funcionando.
  • Seu usuário e senha do SEI e do DARE (os mesmos que você já usa).
  • Os dados de cada DARE: número do processo, CNPJ, CPF do servidor, CNPJ do recolhedor, mês de referência, data de vencimento e valor.
  • Só para o modo planilha: o programa Microsoft Excel.
Autorização Este programa só pode ser usado por pessoas autorizadas pelo autor. Leia o arquivo LICENCA.txt (abre no Bloco de Notas). Não copie nem passe o programa para outras pessoas.

2. Instalação (uma única vez)

Peça ajuda se preferir Este passo é feito só uma vez em cada computador. Se você não se sentir à vontade, peça para a pessoa que lhe entregou o programa fazer esta parte. Depois dela, o uso do dia a dia é bem simples.
  1. Coloque a pasta do programa em um lugar fácil.
    Copie a pasta DARE e Anexar para Documentos (evite deixar em "Downloads"). Não mude o nome dos arquivos que estão dentro dela.
  2. Instale o Python (um programa de apoio, gratuito).
    Abra o site python.org/downloads, clique no botão amarelo Download Python e abra o arquivo baixado.
    MUITO IMPORTANTE: na primeira tela, marque a caixinha "Add python.exe to PATH" (ou "Add Python to PATH"). Depois clique em Install Now e espere terminar.
  3. Instale os componentes do programa.
    Na pasta do programa, dê dois cliques no arquivo instalar.bat. Abrirá uma janela preta com mensagens. Espere até aparecer "PRONTO! Instalação concluída." e aperte qualquer tecla para fechar.
O Windows mostrou "O Windows protegeu seu computador"? Isso é normal em arquivos novos. Se o programa veio de quem você confia, clique em Mais informações e depois em Executar assim mesmo.
Deixe um atalho na Área de Trabalho Clique com o botão direito em executar.bat → Enviar para → Área de trabalho (criar atalho). Assim você abre o programa direto da tela inicial.

3. Como abrir o programa

  1. Dê dois cliques em executar.bat (ou no atalho da Área de Trabalho).
  2. Vai aparecer uma janela preta com letras. Ela é o "painel" do programa. Não feche essa janela enquanto estiver usando.
  3. O Chrome abre sozinho, com duas abas: uma do SEI e outra do DARE. Pode demorar alguns segundos. É um Chrome só do programa; o seu Chrome de sempre não é afetado.
  4. Aperte Enter quando a janela pedir. Aparece o menu principal.

O menu é assim:

║                         DARE AUTOMAÇÃO                         ║

   1  Modo em lotes     (digitar os dados na tela)
   2  Modo planilha     (ler os dados de uma planilha do Excel)
   3  Abrir a pasta dos PDFs
   4  Abrir a pasta de logs
   0  Sair

  › Escolha uma opção: _
Como "escolher uma opção" Digite o número da opção e aperte Enter. Exemplo: digite 1 e Enter.
Se você digitar algo errado, o programa avisa e pergunta de novo. Não tem problema.

Regras de ouro para digitar

  • Enter = "confirmar". Você aperta depois de cada resposta.
  • Quando aparecer algo como [Enter = 100,00], significa que, se você apertar só o Enter, o programa usa esse valor.
  • Para colar um texto copiado (por exemplo, um número de processo), clique com o botão direito do mouse dentro da janela preta. Em algumas versões do Windows, serve Ctrl+V.
  • Para cancelar o que está fazendo e voltar ao menu: segure Ctrl e aperte C.
  • Não precisa digitar pontos e traços de CPF e CNPJ. Pode digitar com ou sem eles.

4. Escolher o modo: digitar ou planilha

ModoQuando usar
1 – Modo em lotes Você tem poucos DAREs (1 a 10) e prefere digitar os dados na tela.
2 – Modo planilha Você tem muitos DAREs ou os dados já estão numa planilha do Excel. O programa lê a planilha linha por linha, sem você digitar nada.

Os dois modos fazem exatamente o mesmo trabalho depois. Só muda a forma de informar os dados.

O que é um "lote"? Um lote é um DARE completo (um processo, um servidor, um valor). Se você vai fazer 5 DAREs, são 5 lotes. O programa faz um lote de cada vez, do primeiro ao último, sem parar.

O programa confere para você Se você digitar um CPF ou CNPJ inexistente, um mês inválido ou um valor estranho, ele mostra uma mensagem em vermelho (✖) explicando o erro e pergunta de novo. Basta digitar certo.

Depois do primeiro lote

  • O programa pergunta "Adicionar outro lote?". Digite s (sim) ou só Enter para adicionar mais um; digite n (não) quando acabar.
  • Nos lotes seguintes, vários campos já vêm preenchidos com o lote anterior (CNPJ, recolhedor, referência, vencimento e valor). Se for igual, é só apertar Enter. Só o processo e o CPF você digita sempre.
Cuidado com o valor 7.243 o programa entende como 7.243,00 (sete mil duzentos e quarenta e três reais). Se o valor é 7 reais e 243 milésimos, ou se tiver dúvida, digite sempre com vírgula e centavos: 7243,00.

6. Modo planilha (usando o Excel)

Aqui você não digita os dados: o programa lê de uma planilha do Excel. Uma linha da planilha = um DARE.

6.1 Preparando a planilha

Você pode usar a sua própria planilha (qualquer formato) ou o modelo pronto do programa. Para criar o modelo: no modo planilha, digite M e Enter. O Excel abre com a planilha modelo.

O modelo tem estas colunas (cada coluna é uma informação):

ABCDEFG
Processo SEICNPJ do órgãoCPF do servidorCNPJ do recolhedorMês/Ano referênciaVencimentoValor (R$)
0012.123456/
2026-12		11222333000181529982247251122233300018110202610/11/20267273,07
A linha 2 do modelo é só um exemplo! Apague ou troque pelos seus dados antes de rodar o programa. Depois salve a planilha (clique no ícone do disquete, no alto do Excel) e deixe-a aberta no Excel.
  • Vencimento e Valor podem ficar em branco: o programa usa "1 mês à frente, em dia útil" e "100,00".
  • Se o Excel mostrar um aviso amarelo "Modo de Exibição Protegido", clique em Habilitar edição. Sem isso o programa não enxerga a planilha.
  • O programa nunca altera a sua planilha. Ele só lê.

6.2 Passo a passo no programa

  1. No menu principal, digite 2 e Enter.
  2. Escolha a planilha.
    O programa mostra a lista das planilhas abertas no Excel. Digite o número da sua e Enter.
    Não achou? Duas saídas: abra a planilha no Excel e digite R (atualizar a lista), ou digite C e escreva o caminho do arquivo (dica: no Explorador, clique no arquivo com o botão direito segurando Shift → "Copiar como caminho", e cole com o botão direito do mouse).
  3. Escolha a aba.
    Aba é cada "folha" da planilha, lá embaixo no Excel (Plan1, Dados...). Digite o número ou o nome. Se houver só uma, o programa já escolhe.
  4. Confirme as colunas.
    O programa tenta descobrir sozinho qual coluna é o processo, o CPF, etc. Ele mostra o resultado e pergunta "Usar estas colunas? [S/n]".
    • Está certo? Aperte Enter.
    • Está errado? Digite n. Aí, para cada informação, digite a letra da coluna (por exemplo C) ou o nome do título da coluna. Se não souber, peça ajuda.
    Na próxima vez que usar a mesma planilha, o programa lembra das colunas.
  5. Escolha de que linha até que linha.
    O programa mostra, por exemplo: "Dados encontrados da linha 2 até a linha 40".
    • Linha inicial: aperte Enter para começar do começo, ou digite o número da linha.
    • Linha final: aperte Enter para ir até o fim da planilha, ou digite o número da linha.
    Exemplo: para fazer só as linhas 10 a 15, digite 10 e depois 15. O número da linha é o que aparece na lateral esquerda do Excel.
  6. Veja o resultado da leitura.
    O programa mostra quantas linhas estão certas. Linhas com problema (por exemplo, CPF inválido) aparecem listadas com o número da linha e o motivo, e ficam de fora. Ele pergunta se você quer continuar só com as linhas certas. Se quiser corrigir a planilha antes, responda n, corrija no Excel, salve e comece de novo.
Linhas em branco e escondidas Linhas totalmente vazias e linhas escondidas por filtro são puladas automaticamente.

8. Entrar nos sistemas (login)

Ao iniciar, o programa pede que você entre com a sua conta no SEI e no DARE:

┌─ Antes de continuar ───────────────────────────────────────────┐
│ 1. Na aba do DARE e na aba do SEI, entre com a sua conta.      │
│ 2. Quando as duas estiverem logadas, volte aqui.               │
└────────────────────────────────────────────────────────────────┘

  Pressione Enter quando estiver logado nos dois sistemas...
  1. Olhe a janela do Chrome que o programa abriu (se ela estiver escondida, clique no ícone do Chrome na barra do Windows).
  2. Na aba do SEI, digite seu usuário, senha e entre normalmente.
  3. Na aba do DARE (clique na aba para trocar), faça o mesmo, se pedir.
  4. Volte para a janela preta e aperte Enter.
Boa notícia Nas próximas vezes, o Chrome do programa costuma lembrar do seu login. Se já estiver logado, é só apertar Enter. Você só confirma o login uma vez por vez que abre o programa (não a cada lote).

9. Enquanto o programa trabalha

Agora o programa faz tudo sozinho: preenche o DARE, salva o PDF e anexa no SEI. Você vai ver o Chrome trocando de aba e preenchendo campos sozinho. Isso é o esperado.

Enquanto estiver trabalhando, NÃO:
  • mexa no mouse nem no teclado dentro do Chrome do programa;
  • feche a janela preta nem o Chrome do programa;
  • clique em botões do DARE ou do SEI;
  • deixe o computador entrar em suspensão ou desligar (se for demorar, configure o Windows para não suspender).
  • Você pode fazer outras coisas em outras janelas (Word, e-mail), mas sem tapar o Chrome do programa e sem mexer nele.
  • Cada DARE leva alguns instantes. Com muitos lotes, o total pode demorar. Tenha paciência.
  • Aparecem mensagens na janela preta como ✔ Lote 1/5 concluído. Quando um lote falha: ✖ Lote 3/5 falhou. O programa não para: ele segue para o próximo lote.
  • Se o Chrome do programa for fechado sem querer, o programa tenta abri-lo de novo.
Precisa parar? Na janela preta, segure Ctrl e aperte C. O programa para com segurança e guarda o que ficou sem fazer, para você continuar depois.

10. Quando terminar

No final o programa mostra um resumo:

┌─ Resumo dos lotes ─────────────────────────────────────────────┐
│ ✔ Lote 1: 0012.123456/2026-12 · NOME DO SERVIDOR               │
│ ✖ Lote 2: 0012.123456/2026-99 · 529.982.247-25                 │
│    ↳ TimeoutError: ...                                         │
│                                                                │
│ Concluídos: 1 · Com erro: 1 · Total: 2                         │
│ PDFs em: C:\Users\...\DARE e Anexar\DARE_PDFs                  │
└────────────────────────────────────────────────────────────────┘
  • ✔ (verde) = deu certo: o DARE foi gerado, salvo e anexado no SEI.
  • ✖ (vermelho) = deu erro nesse lote.

Se algum lote deu erro

O programa pergunta: "Tentar de novo os lotes com erro? [s/N]".

ATENÇÃO antes de tentar de novo Às vezes o erro acontece depois que o DARE já foi gerado (por exemplo, na hora de anexar no SEI). Nesse caso o resumo mostra: "O DARE foi gerado, mas não anexado" e o caminho do PDF. Não refaça esse lote sem conferir, senão você pode gerar um DARE repetido. Confira no SEI se o documento foi anexado. Se não foi, anexe o PDF que está salvo na pasta.

Onde estão os PDFs?

  1. No menu principal, digite 3 e Enter.
  2. A pasta DARE_PDFs abre sozinha, com todos os PDFs. Cada nome tem o servidor, o CPF, o mês e o vencimento.

Para sair

No menu principal, digite 0 e Enter. Depois pode fechar a janela do Chrome do programa.

11. Se algo der errado

Primeiro, respire. O programa não apaga nada seu. Veja a tabela:

O que aconteceuO que fazer
Ao clicar em executar.bat, a janela abre e fecha na hora, ou diz que não acha o Python. A instalação não foi feita. Dê dois cliques em instalar.bat e siga as mensagens.
"Falta instalar uma dependência". Dê dois cliques em instalar.bat (com internet).
O Chrome não abriu. Feche todas as janelas do Chrome, feche o programa e abra de novo. Se persistir, dê dois cliques em iniciar_chrome_debug.bat e depois use o programa.
O programa parou e fica "esperando" na aba errada. Não mexa. Se passar de alguns minutos, aperte Ctrl+C na janela preta e comece de novo. Os lotes pendentes serão oferecidos para retomar.
Apareceu "Há N lançamento(s) pendente(s)... Retomar?" É o programa lembrando de lotes que não terminaram. Enter (Sim) continua de onde parou; n descarta e começa do zero.
O CPF/CNPJ foi recusado ("inválido"). Confira os números, um por um. O programa confere os dígitos finais para evitar erro de digitação.
Minha planilha não aparece na lista (modo planilha). Ela precisa estar aberta no Excel e com a "Edição habilitada". Digite R para atualizar a lista, ou C para digitar o caminho do arquivo.
"A biblioteca pywin32 não está instalada". Dê dois cliques em instalar.bat. O modo planilha precisa do Microsoft Excel.
Uma linha da planilha foi ignorada. A janela mostra o número da linha e o motivo (por exemplo, "CPF inválido"). Corrija na planilha e rode de novo só essa linha (escolha a mesma linha como inicial e final).
O SEI ou o DARE mudou e o programa "não acha" um botão. Os sites podem mudar sem aviso. Avise quem lhe entregou o programa e mande o arquivo de registro (veja abaixo).

Como pedir ajuda

  1. No menu, digite 4 e Enter: abre a pasta de registros (logs).
  2. Envie para quem lhe entregou o programa o arquivo dare_automacao.log e, se houver, as fotos da pasta erros. Conte o que você estava fazendo e o que apareceu na tela (se puder, tire uma foto da tela).

12. Cuidados com os dados

O programa lida com CPF, CNPJ e nomes de servidores. São dados protegidos pela lei (LGPD).

  • Não envie a pasta do programa por e-mail ou WhatsApp. Ela contém seu histórico com dados reais.
  • Não deixe o computador desbloqueado com o programa aberto. Bloqueie a tela (Windows+L) ao sair.
  • Guarde planilhas com dados em pastas só suas. Apague as que não precisa mais.
  • O programa guarda no seu computador, nas pastas dados, logs e DARE_PDFs, o histórico do que foi feito. Apague essas informações quando não forem mais necessárias.
  • Nunca diga sua senha a ninguém. O programa não pede nem guarda sua senha: você a digita nos sites, como sempre.
  • O programa é de uso restrito a pessoas autorizadas. Veja LICENCA.txt.
